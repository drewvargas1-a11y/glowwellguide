Ice globes work by freezing for a couple of hours before use, then rolling across the face for a cold-therapy massage that can reduce puffiness, calm redness, and — done right before applying serum — help active ingredients penetrate more effectively into cooled, temporarily tightened skin.

We compared cooling duration, handle comfort, and whether each set includes a proper storage case, since these tools live in the freezer between uses and need a hygienic way to store there.
